Bank Management System
======================
Features
--------
- Low-Scale Bank System with Basic Functionalities
- Bank Client Functionalities:

  - Deposit
  - Withdrawal
  - Transferal
- Client Accounts Management Functionalities:

  - Creation
  - Modification
  - Deletion
- Employee Accounts Management Functionalities:

  - Creation
  - Modification
  - Deletion
- Data stored in .txt files:

  - Client accounts
  - Employee accounts
  - All processed transactions
